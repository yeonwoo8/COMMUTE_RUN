# CLAUDE.md — 럭키 출근길 (Official 2026 Unity Game Jam)

## 프로젝트 개요
- **게임:** 출근길에 숫자 3이 들어간 행운을 클릭해 모으고, 할당량을 넘겨 돈을 버는 2D 도트 클릭 액션
- **잼 주제:** Lucky Number → 한국의 행운 숫자 **3** (불운 숫자는 **4**)
- **개발:** 1인, 7일
- **마감:** 2026-11-14(토) 21:00 KST (= 12:00 UTC). 마감 후 파일 수정 불가

## 잼 필수 규칙
- Unity로 제작, **WebGL 빌드 필수** (itch.io 브라우저 실행)
- 에셋은 무료/구매 가능, **모든 출처 크레딧 표기**
- 생성형 AI 사용 시 **도구와 사용 범위를 제출 페이지에 공개**
- 심사: 주제(×2 가중치), 디자인 구현, 아트·오디오 통일성, 컨셉

## 핵심 루프
1. **아침 TV:** 오늘의 행운 할당량 표시 (1일차 50 → 2일차 60 → 3일차 70)
2. **출근길 (60초):** 주인공 자동 전진, 마우스 클릭으로 행운 수집. 상단에 집 ──●── 회사 진행 게이지
3. **회사 컷씬:** 할당량 넘으면 성공 → 돈 버는 애니메이션, 못 넘으면 꾸중
4. 총 3일. 실패하면 그 일차를 처음부터 다시, 성공하면 다음 일차로
5. 3일차 성공 → 결과 화면 → 클릭하면 타이틀로 돌아가 1일차부터

## 일차별 이벤트
| 일차 | 이벤트 |
|---|---|
| 1일차 | 기본 요소만 |
| 2일차 | 초반(15%)에 황금클로버 상자 하나 더 (열쇠 필요). 후반(86%)에 황금클로버를 묻는 사람: 클로버가 있으면 클릭해 +10 (클로버는 유지) |
| 3일차 | 비 오는 날: 화면이 어둡고 빗소리, 번호판이 드물게 나옴. 우산 클릭 시 +5, 12초간 비가 그침. 후반(86%)에 황금클로버를 묻는 사람 |

## 행운 아이템
| 아이템 | 조작 | 행운 | 함정 |
|---|---|---|---|
| 번호판 (4칸, 차·버스) | 3이 적힌 칸 클릭 | 칸마다 +1 | 4는 클릭되지 않는 칸으로만 등장 |
| 오락실 슬롯 (15초마다) | 길가의 기계를 클릭해 열고, 클릭으로 릴 3개를 하나씩 멈춤 | 3 한 개 +3, 두 개 +6, 333 +33 | 444: -5 |
| 얼룩진 간판 (20초마다) | 간판의 얼룩을 좌우로 6번 문질러 떨어뜨림 | +3 | 없음 |
| 까치 (8~14초마다) | 위쪽을 물결치며 빠르게 날아가는 까치 클릭 | +2 | 없음 |
| 빵 달라는 사람 | 빵을 들고 있을 때 클릭해 빵 전달 | +3 | 없음 |
| 황금클로버 묻는 사람 (2·3일차) | 클로버가 있을 때 클릭 | +10 | 없음 |
| 우산 (3일차 비 오는 날) | 인도로 흘러오는 우산 클릭 | +5, 12초간 비가 그침 | 없음 |

- 번호판 당첨 칸 수 확률(`plateWeights`): 0칸 35, 1칸 30, 2칸 10, 3칸 5, 4가 섞인 판(당첨 1~2칸) 20
- 오토바이는 차선을 지나가는 장식이고 점수는 없다
- **삼세번 콤보:** 행운을 3번 연속 얻으면 이후 획득 ×2. 9연속이면 4초 동안 피버 ×3 (피버 중에는 번호판 4칸이 모두 3). 2.5초 동안 아무것도 못 얻거나, 444가 나오거나, 행인과 부딪히면 콤보가 끊긴다 (피버 중에는 안 끊김)
- **황금클로버:** 얻은 뒤로는 행운을 얻을 때마다 33% 확률로 ×2 (콤보 배율과 곱해짐). 일차가 지나도 유지되고, 타이틀에서 새 게임을 시작할 때만 사라진다
- **방해 요소:** 3일차 비(화면이 어둡고 번호판이 드물게 나옴, 우산 클릭으로 12초간 그침), 불운 숫자 4

## 사람과 빵
- 사람은 4초마다 한 명씩 인도를 오른쪽에서 왼쪽으로 걸어온다
- **빵 떨어뜨리는 사람 (하루 최대 4명, 60% 확률):** 플레이어와 부딪혀 넘어지면서 빵을 떨어뜨린다 (콤보 끊김). 빵을 클릭하면 인벤토리에 들어간다
- **빵 달라는 사람 (하루 최대 1명, 클로버가 있으면 3명, 빵이 있을 때 60% 확률):** 말풍선을 띄우고, 클릭해 빵을 주면 3이 담긴 복권과 행운 +3
- **열쇠 교환 (50%, 65% 지점):** 빵 2개를 원하는 사람에게 클릭해 주면 열쇠를 받는다. 이미 열쇠나 클로버가 있으면 나오지 않고, 클로버가 있을 때는 그 2자리만큼 빵 달라는 사람 상한이 늘어난다
- **보물 상자 (80% 지점):** 열쇠로 열면 황금클로버. 열쇠가 없으면 흔들리기만 한다. 2일차에는 15% 지점에 상자가 하나 더 나온다 (역시 열쇠 필요). 이미 클로버가 있으면 두 상자 모두 나오지 않는다
- **그 외 행인:** 부딪히지 않고 지나간다
- 횟수 제한은 출근길 1회(하루) 기준. 실패해서 다시 하는 날도 새로 센다
- **인벤토리:** 화면 하단 5칸. 빵·열쇠 등 어떤 아이템이든 담는다 (클로버는 옆 배지에 따로 표시)
- 인벤토리는 일차가 지나도, 실패해서 다시 해도 유지된다. 타이틀에서 새 게임을 시작할 때만 비운다 (클로버도 함께). 아이템은 쓸 때만 빠진다 (빵 전달, 빵 2개→열쇠, 열쇠로 상자 열기)

## 점수
- 성공: 30,000원 + (행운 − 할당량) × 3,000원
- 실패: 행운 × 300원
- 총 급여 = 성공한 날의 급여 합계. 실패한 날의 급여는 회사 화면에만 표시되고 합산하지 않는다 (일부러 실패해 늘리는 것 방지)
- 결과 화면: 일차별 급여, 재도전 횟수, 총 급여, 최고 기록 (PlayerPrefs `BestPay`, 갱신 시 NEW BEST!)

## 기술 설정
- Unity 6 LTS, 템플릿 **Universal 2D (URP)**, 플랫폼 **Web**
- Publishing: Compression **Gzip** + **Decompression Fallback** 체크
- 화면 640×360 (Pixel Perfect Camera, PPU 32) → 1280×720 출력
- 스프라이트: Filter **Point**, Compression **None**, PPU **32**
- 입력: 마우스 클릭만 (Input System)
- 한글 폰트는 파일 직접 포함 (WebGL 기본 폰트에 한글 없음)
- 프로젝트 경로·파일명은 영문만

## 코드 규칙
- 간단하고 읽기 쉽게. 잼 범위 밖 기능 추가 금지
- 수치(할당량, 점수, 속도)는 ScriptableObject나 한 곳에 모아 밸런스 조절 쉽게
- WebGL에서 안 되는 것 피하기: 멀티스레드, System.IO 파일 저장, 무거운 후처리
