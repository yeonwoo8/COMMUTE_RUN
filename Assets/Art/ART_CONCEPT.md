# 럭키 출근길 아트 컨셉

새 도트를 그릴 때 이 문서의 색상과 크기에 맞춘다.

## 분위기
- 90년대 시티팝 감성의 서울. 해 뜰 녘 분홍·보라 하늘 아래 상가 거리를 걷는 출근길
- 밝고 납작한 색면에 어두운 테두리를 두른 도트
- 그라데이션, 반투명 픽셀 없음. 픽셀은 완전 불투명 또는 완전 투명
- 하늘은 그라데이션 대신 가로 띠 3단으로 나눈다 (위 라벤더 → 분홍 → 지평선 복숭아)
- 주제 숫자: 행운의 **3**(빛 반사가 살짝 있는 검정), 불운의 **4**
- 거리의 랜드마크는 **"오락실" 한글 네온 간판** (숫자 3은 번호판·슬롯에 맡긴다)
- 미신 소품을 몇 군데 섞는다: 복권방, 점집(빨간 등), "삼삼" 간판. 거리 전체를 미신 가게로 채우지는 않는다
- 휑하지 않게, 사람이 사는 거리처럼 촘촘하게. 풍부함은 해상도가 아니라 **겹(레이어) · 밀도 · 움직임**으로 만든다

## 기술 규격
| 항목 | 값 |
|---|---|
| 게임 화면 | 640×360 (출력 1280×720) |
| Pixels Per Unit | 32 |
| Filter / Compression | Point / None |
| 파일명 | 영문만 |

화면에서 도트 1px은 Canvas 1유닛, 월드 1/32유닛이다. UI 이미지는 스프라이트 원본 크기나 정수배로만 쓴다.

- 하늘과 벽이 따뜻해진 만큼 간판, 네온은 바꾸지 않아 배경보다 튀게 둔다
- 색이 더 필요하면 위 색의 명도만 조절해서 만든다. 어두운 면은 원색의 약 72%를 기준으로 한다

## 배경 건물 (`Buildings_A.png`, `Buildings_B.png`, `Buildings_C.png`)
- 크기 640×140, 가로로 끊김 없이 반복된다
- 2~3장을 만들어 무작위로 이어 붙인다. 한 장만 반복하면 출근길 60~90초 동안 같은 거리를 6~9번 보게 된다
- 세 장 모두 양 끝 20px은 같은 높이·같은 색 건물로 맞춰, 어떤 순서로 붙여도 이음새가 맞게 한다
- 오락실 네온 간판은 한 장(A)에만 넣는다. 랜드마크가 여러 번 나오면 랜드마크가 아니다
- 그림 맨 위가 화면 맨 위와 맞닿는다. 높은 건물은 화면 위로 잘리게 그린다
- 건물 사이에 틈을 두지 않고, 낮은 건물 뒤로 먼 스카이라인이 보이게 한다
- 벽 테두리 3px, 옥상 난간 4px
- 옥상 소품: 물탱크, 실외기, 안테나, 옥상 광고판
- 1층 소품: 유리 진열창, 줄무늬 차양, 양문, 반쯤 올라간 셔터, 공중전화
- 한글 간판: 층별 가로 간판과 건물 옆 세로 간판 (오락실, 비디오, 복권, 다방, 점, 24)
- 간판 테두리에 네온관(분홍·하늘색)을 1px로 두른다. 모든 간판이 아니라 한 화면에 2~3개만
- 문은 모든 건물에서 크기와 모양을 같게 한다
- 작은 디테일을 촘촘히: 전선, 에어컨 배관, 간판 나사, 붙은 전단지, 창가 화분, 빨래

## 앞 레이어 (`Foreground.png`)
- 주인공보다 앞에서 건물보다 빠르게 지나가는 사물: 전봇대와 전선, 버스 정류장, 신호등
- 배경보다 한 단계 어둡게(원색의 약 72%) 그려 앞에 있는 느낌을 준다
- 사물 사이 간격을 넉넉히 둔다 (화면 폭 640px에 2~3개)
- **클릭 대상(번호판, 슬롯, 빵 등)을 가리면 안 된다.** 클릭을 막지 않게 Raycast Target 끄기 / 콜라이더 없음
- 스크롤 속도: 건물 1배 기준으로 먼 스카이라인 0.3배, 앞 레이어 1.5배

## 인도 소품
- 자판기, 화분, 전단지 붙은 기둥, 쌓인 박스, 우체통, 공중전화, 화단 나무
- 사물은 빛을 받는 오른쪽 가장자리를 밝게, 왼쪽을 어둡게 하고 그림자는 왼쪽 바닥으로 드리운다
- 화단 나무: 건물 쪽 인도 끝에 둔다. 사람 키의 약 1.5~2배. 1px 단위 잎사귀에 빛은 오른쪽 위에서 받는다 (윤곽 `#ffd3a8`, 왼쪽 아래에 하늘 반사 `#9a86c4`, 그림자는 왼쪽으로)
- 클릭 대상과 헷갈리지 않게 소품에는 금색(`#ffe08a`)과 네온 반짝임을 쓰지 않는다

## 움직이는 것
2~4프레임, 8~12fps 정도의 작은 루프 애니메이션.

| 대상 | 프레임 | 비고 |
|---|---|---|
| 네온 간판 깜빡임 | 2 | 켜짐 / 꺼짐, 간판마다 시작 타이밍을 다르게 |
| 실외기 연기 | 3 | 옥상 |
| 현수막 펄럭임 | 3 | 건물 앞 |
| 비둘기 | 2 | 지붕·전선 위, 가끔 날아감 |
| 오토바이 | 2 | 차선 위로 지나감, 클릭 대상 아님 |

## 발광 (`Glow_*.png`)
- 네온 간판 뒤에 부드러운 원형 빛 스프라이트를 깐다 (네온 분홍·하늘색)
- **반투명 픽셀 금지 규칙의 유일한 예외.** 도트 그림 자체에는 반투명을 쓰지 않는다
- 한 화면에 3~4개까지

## 글자와 숫자
TextMeshPro 글자 대신 도트 이미지를 쓴다. 외부 폰트 없이 격자에 직접 찍은 글자다.

| 종류 | 크기 (px) | 스타일 |
|---|---|---|
| 번호판 숫자 | 칸 12×14, 숫자 6×10 | 2px 획, `#1c1230`, 3×5 격자 기반 |
| 번호판 판 | 52×18 | 흰 바탕, 1px 테두리, 모서리 깎음 |
| 당첨 3 | 12×14 | 번호판 숫자와 같은 형태의 검정, 오른쪽 위에 빛 반사 몇 픽셀만 |
| HUD 숫자 | 11×18 | 흰 글자, 2px 획, 테두리 없음. 세 자리로 표시 (`007`) |
| HUD `LUCK` | 47×18 | HUD 숫자와 같은 형태, 금색 글자 |
| HUD 점수판 (`HudPanel.png`) | 100×28 | 어두운 보라 패널, 숫자 칸 3개, 분홍 네온 구분선 |
| 슬롯 릴 숫자 | 22×36 | HUD 숫자의 정확한 2배 |
| 건물 간판 글자 | 8칸 높이의 2배 | 격자로 찍은 한글 |

3은 튀지 않게 살짝만 강조한다. 숫자 4는 다른 숫자와 같은 색으로 둔다.

## 화면 배치
Canvas 좌표 기준이고, 화면 중앙이 (0, 0)이다.

| 요소 | 위치 |
|---|---|
| 건물 바닥, 인도 윗선 | y = 40 |
| 주인공 발 | y ≈ 5 |
| 차선 바닥 | y = -156, -76 |

그리는 순서 (뒤 → 앞): 하늘 → 먼 스카이라인 → 발광 → 건물 → 인도, 도로 → 인도 소품 → 표지판, 슬롯 기계 → 주인공 → 앞 레이어 → 슬롯 게임 창 → 행인, 빵 → 차량 → HUD

- 앞 레이어는 주인공 앞, 행인·빵·차량 뒤에 둔다
- 슬롯 기계, 표지판, 건물 가격표는 앞 레이어보다 뒤라 잠깐 가려질 수 있다. 그래서 앞 레이어는 전봇대처럼 얇은 사물 위주로 하고, 가려져도 클릭은 통과하게 한다
